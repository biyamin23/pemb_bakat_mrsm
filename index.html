🔌 Sambungan Database Google Sheets

Integrasi Cloud Database MRSM Kuching via Google Apps Script

💡 Cara Dapatkan Web App URL:
  1. Buka Google Sheets baru & tampal kod google-apps-script/Code.gs ke Apps Script.
  2. Tekan Run pada fungsi initDatabase sekali untuk jana 6 helaian automatik.
  3. Klik Deploy > New deployment > Web app (Access: Anyone).
  4. Salin URL Web App dan tampal di bawah. Rujuk Panduan Lengkap.
Pastikan URL berakhir dengan /exec.
